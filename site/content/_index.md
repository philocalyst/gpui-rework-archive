These docs describe the current checkout. They assume you can read Rust structs,
closures, and trait implementations; they introduce GPUI's own concepts as you use them.

GPUI Community Edition is a fork of [Zed's GPUI](https://gpui.rs). It shares its
origins and many APIs, but a recipe from another fork can require changes here.
Start with the [version guide](@/reference/versions.md) when moving code between them.
