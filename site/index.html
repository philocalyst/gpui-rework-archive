Fast, GPU-rendered interfaces in Rust.

GPUI draws your interface on the GPU at the speed of your display. Describe it with flexbox and Tailwind-style methods, keep state in entities that GPUI tracks for you, and ship it on macOS, Windows, Linux and the web.

What GPUI gives you

GPUI was built to make the Zed editor. Everything it needed is in the box.

Rendered on the GPU

Metal, DirectX, Vulkan or WebGPU draw every frame, so scrolling and motion stay smooth.

Layout you already know

Flexbox and grid, styled with methods like .flex(), .gap_4() and .rounded_lg().

State with one owner

Entities share mutable state without RefCell and tell GPUI exactly what changed.

Keyboard first

Typed actions, key bindings with contexts, and focus handling are built in.

Motion

Animations, springs and style transitions, with one switch to reduce motion app-wide.

Made to be tested

Drive views headlessly with simulated input and a deterministic scheduler.
