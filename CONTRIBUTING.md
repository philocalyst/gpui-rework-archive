# Contributing to GPUI-CE

Bug reports, examples, documentation, and code changes are welcome. Join the [Discord](https://discord.gg/ENGHGjrYEn) or [open an issue](https://github.com/gpui-ce/gpui-ce/issues) to discuss a change. For larger API or architecture changes, start that discussion before writing the implementation.

View the [setup guide](SETUP.md) for installation instructions.

Documentation is part of the code: the API reference, tutorial, guides and examples are all built and tested by rustdoc and cargo. [Writing GPUI documentation](docs/writing-docs.md) explains where each kind of page lives and the style they follow.
