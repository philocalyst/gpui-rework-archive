# Paired GPUI capture: frozen 724 versus current dcdadf4

Capture completed 2026-10-21 22:14:43 UTC; it started 22:13:50 UTC. The runner validated all six source/workload identities before launching, then rechecked source, manifest, binary and observer identities before each observer process. The 724 baseline and current dcdadf4 builds use the same fixture SHA and native-default `x11`/`RendererPolicy::Auto` profile. The raw records contain the per-cell binary identity and every sample. `summary.csv` is a derived descriptive table only; the full event rows remain in the six `.raw` files.

Each cell has 100 fresh starts, 1,000 click-to-marker acknowledgements and five idle memory samples (750 ms per sample). Startup/click values are observer nanoseconds to exact Xvfb drawable pixels after XDamage; they end at the X server drawable, not compositor, vblank, scanout, or photons. Memory samples are RSS/PSS KiB and process thread counts from `/proc`; five samples per cell are too few to characterize a memory distribution, so the table reports median and observed min/max only.

All GPUI applications requested `Auto` and the separate accepted preflight/backend probe selected `ReferenceCpu` on this host. The capture does not show hardware GPU acceleration. Both binaries include the x11 AccessKit backend, but the user session's `org.a11y.Bus` was not activatable during preflight; this is not an active assistive-technology session. The workloads are only eager 0, eager 1,000 and virtual 250,000. Virtual materialization differs by framework in the broader peer campaign, but this is a GPUI-to-GPUI comparison with the same fixture and requested rows.

Order alternated by workload: baseline/current for eager 0, current/baseline for eager 1,000, baseline/current for virtual 250,000. These are sequential 100-start blocks, not individually paired application launches; do not infer per-event paired confidence intervals. No cells were dropped or selected after observing results. This capture is separate from the earlier NanoUI/MyGo comparison and must not be combined with that campaign as if it were a same-session three-framework run.
