## Ownership and admission

Small `Copy + Send + Sync + 'static` recipes retain sixteen bytes of checked,
eight-aligned inline payload plus a function pointer. Explicit parameters and
captures together must fit that payload. Oversized/overaligned recipes return
mount admission errors; no hidden heap fallback exists. Recipes must be total,
deterministic and read-only. Rust cannot prove that semantic law.

Concrete non-generic fanout helpers freeze and validate every output before
publishing destinations. Old color-bank values remain authoritative throughout
all comparisons, including masked peers sharing a direct color slot. Mapped
color slots are stable and bounded by mounted relationships. The negative
controls in the producer evidence catch unbounded color growth and prematurely
published shared colors. Iterative element decomposition removes the initial
mapped implementation's recursive aggregate copies.

A clean contiguous scene with one effective mapped color change uses the same
alpha-checked Canvas transaction as an ordinary direct color source. It reuses
complete geometry and retains old acknowledged authority until actual ACK.
Multiple effective colors and alpha changes fall back to complete preparation.
Mounted inspector captions refresh after completion. No retained field, extra
public paint-edit interface or alternate inspector authority is introduced.

## Executed qualification

Final source passes 637 default tests across 70 harnesses, with ten explicitly
ignored native cases, and strict default/native all-target Clippy. Native
execution passes 226 ordinary library tests plus the actual X11 Todo/paint
bridge, with 30 other native cases explicitly ignored. The bridge compares
direct and mapped SDR/HDR output with complete-render CPU oracles, including
negative/out-of-gamut linear channels, subnormals, signed zero, alpha changes
and coalesced tokens. HDR tolerance is one ordered finite f16 ULP, identifying
numeric signed zeros; SDR uses the existing byte tolerance. These llvmpipe
results are not physical GPU/backend conformance or performance measurements.

The public 10,000-row recording fixture proves zero requested allocations for
first and warmed single-effective-color updates, unchanged complete geometry,
pixels and stale authority before ACK. The same regression on the original
mapped source fails: six allocations request 1,200,712 bytes, retaining 640,208.
This isolated fixture differs from the producer's automatic-surface color
fixture; those figures are not pooled. Its original and fixed executables are
retained. The final combined fixture additionally checks mounted-inspector
refresh and alpha/multiple-color fallback.

The new unsafe helper contains 50 shipping lines and two checked pointer
