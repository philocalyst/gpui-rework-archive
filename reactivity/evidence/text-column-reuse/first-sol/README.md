# Reuse an unchanged acknowledged text column

Production source is based directly on main `a50b3b85121be0a5741b4733db977173c01806d2`. The reviewed implementation is `bd09cb1a971f0fb37e310b882a3a45c2eff5ef42`; final test-only corrections are `a7604140e643a1ef87d6a706c2125c4a7066ca64`. Matched baseline `fb088ab7f7b54fabcaaab5c19c14d824ecd48c1e` has unchanged main production and the byte-identical owner fixture (SHA256 `6739d77ac13aa1543fa67c5c9794a84dede9fbb029bad16f38c202c3e89dc8c8`). Neither implementation depends on the separate row-overlay prototype.

During the existing admitted visual-row walk, an optional local text vector stays `None` while each text entry matches P's exact text-entry order, published row index, origin float bits, and immutable borrowed map pointer. The first mismatch allocates a full replacement, copies the already proven prefix, and retains maps for the remaining admitted text rows. Shortening without an earlier mismatch materializes only the surviving prefix; removing all text installs `Some(empty)`. `None` reuses P through the existing acknowledge operation. Successful C2 reuse retires an older full C1 only at the existing successful commit tail; failed C2 changes neither P nor C1. Candidate accessibility comparison receives the exact borrowed resolved Entry.

The full replacement reserves `min(previous text count, current logical node count)`. After emission, local scratch shrinks only if capacity exceeds four times its known final length. This bounds topology contraction and prevents indefinite excess when nontext rows survive. It adds no full proof scan or map clones. Shrinking can add a reallocation and buffer move; it occurs before the existing Canvas/column commit tail. Ordinary P queries remain direct.

## Source, type and work bill

Committed Syn/Tokei counts across the six shipping libraries, including build scripts and excluding tests/comments/examples/tools/vendors: baseline **30,681**, candidate **30,731**, delta **+50**. `core-lines-baseline.json` and `core-lines-final.json` identify source pins and tool/source hashes. The first working policy was +42; reserve/finish refinements add eight lines.

No public API, dependency, unsafe operation, owner field or per-node field is added. Both binaries report identical 64-bit headers: TextResources 120, Entry 24, Runtime 1824, TextSite 80, Node 40, Presented 64, Prepared 40, Part 16 bytes. The existing 24-byte Vec local becomes a 24-byte Option<Vec>; the placed geometry tuple uses a borrowed map-bearing layout instead of an Arc with the same pointer-sized component. Two named usize locals charge 16 bytes at source level, including the named existing row-loop bound. The helper has seven arguments, an 8-byte Option<&Entry> result used for per-row accessibility comparison, and a temporary 24-byte Vec header on fallback; no generated-frame/optimized stack-size claim is made.

Every admitted text row calls the helper and branches on optional candidate ownership. Until divergence it checks row equality, two origin bit equalities and immutable map pointer equality; after divergence it retains one map per remaining row. First divergence copies/retains the already matched prefix once, reserves a bounded full column, and does the existing full emission thereafter. A changed column pays the full vector and map-handle cost. Tail checks detect shortening and excessive capacity once per preparation. No source-generation shortcut, new borrowed Vec, extra unchanged-column proof pass, or universal visual epoch is introduced.
