# Bounded publication directory and combined chunk-to-pixel path

Baselines: first pair36f700a734; incremental chunks57ccf254851e12839da4b5deedd5c7047b686c80.
Prior byte-lifetime and restricted-binding subgates do not yet compose into the
user's end-to-end target. This next isolated branch must resolve that gap.
Keep all changes local; unchanged application APIs, no adoption/timing claim.

Decisive trace: ordinary public Source property assignment -> registered identity
-> authoritative compressed chunk mutation -> old/new damage -> COW directory
path -> actual GPU decode -> retained pixels. Initial admission can scan once;
subsequent point edits must not materialize a scene, mirror or whole directory.
Sweep1/9/32/256/1024 admitted records with the same edit. Report public/runtime
work and restricted fixture binding separately from generic production support.
Compare raw fallback, compressed chunks, and a serial uncompressed control.

Use a fixed32-way, two-level COW address directory with explicit admitted bound
32768 slots; each page entry carries payload address/count. Stable identities
and generational addresses retain their independent index cost. Directory and
resource updates are delta journals; do not silently enumerate unchanged entries.
Charge every path copy, refcount edge, resource entry examined, encoded/decoded
row/word, old/new damage operation, CPU scratch, allocation bin/fragmentation,
GPU upload (including padding), descriptor, and prepared/submitted/visible lease.
Point publication bounds apply only inside the explicit directory-capacity domain.
Retain the97-node subtree move as a charged O(k) structural counterexample.

Actual pixels: preserve independent full GPUI/Canvas rendering and the first-pair
full-render oracle. Exercise clipped/overlapping opaque rectangles, resource
replacement, stale/rejected candidates, deferred-oldest submission and out-of-
order completion notifications. Test root-addressed real glyph/image bytes too;
byte auditing is supplementary, never a replacement for final pixel equivalence.
Old candidate output must not corrupt the acknowledged image or resources.
Any restricted geometry/resource renderer must explicitly reject unsupported
cases and report those restrictions; no general GPUI parity claim from fixtures.

Lifetime: immutable COW pages/roots until all semantic and submitted fences
release them. Preserve staged writes as baseline; they are not coherent shared
host memory. A fixed-size descriptor is not fixed total update or rendering work.
Bounded mutants: wrong directory path/count, omitted old damage, missing resource
lease, stale authority and premature range reuse must fail independent oracles.

Freeze clean source before every execution gate, fresh unique target, pinned
locked/checksum builds, source/font/driver/executable/embedded WGSL identities,
full actual readbacks, failed gates and rederiving verification. No timing or
ZGX inference until a separately preregistered equivalent measurement passes.
Next handoff includes a compact requirement matrix: implemented in model,
restricted adapter only, or still missing, beside the measured structural costs.
