# Stage B1/C1: actual resource bytes and restricted public direct binding

This subgate does not yet replace the production renderer or implement the
bounded COW publication directory. The Stage A flat root table remains charged.
The existing serialized first-pair renderer is unchanged as an exact baseline.

`direct_resources` admits a nine-node public View once, caches its named Target,
then uses unchanged Win::set and property APIs for16 point edits without further
snapshot, bounds or draw enumeration. A fixture-specific registered binding
routes that destination to the chunk index. Fresh full Views and CPU pixels are
explicit separate oracles. Generic automatic runtime binding is still missing.
Two candidates are invalidated before public acknowledgement. Real borrowed
DejaVuSans glyph coverage and RGBA8 image bytes are copied through PreparedScene,
then all owning windows/fonts are dropped; the copies' bytes/lifetimes are charged.

`lifetime_gpu` feeds those edits and actual assets to compressed/raw chunks and
publication roots. Compare serial waits with three overlapping root leases;
in each triple, defer the oldest command buffer and submit it after newer
writes. Consume every byte through the immutable root's child addresses on
actual Vulkan and preserve mapped output. Complete CPU fence notifications in
reverse order, reclaim only after semantic and submitted leases release, then
reuse ranges in later triples. Padding, root tables, parameters and retained
allocation high-water all count. Visible/eligible authority remains a separate
CPU model; this byte audit is not actual window presentation or a general
text/image renderer. The current resource table rebuild also has linear cost.

Bounded mutant: omit only resource child leases from a root while retaining its
root/page ownership and all pointer bytes. Replacing resources can then reuse
old addresses before the deferred consumer executes. The actual GPU must reject
its byte output. A normal single ordered-queue overwrite after a completed read
would not falsify this bug; deferred consumption is deliberate and specified.

Freeze before building/running. Fresh unique target, pinned locked/checksum
build, source guards, exact font digest, actual ELF/embedded WGSL, all actual
readbacks and failure logs. Any failure is preserved; no performance verdict.
