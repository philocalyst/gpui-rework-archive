# Incremental ordered chunks and fenced publication: preregistration

Keep first-pair36f700a7345e7a561c66de498f840437ad4f0d3c unchanged as baseline.
This isolated branch tests its explicit counterexamples, not a new timing claim.
Existing shipping application API remains unchanged; all changes stay local.

Compare compressed stable slots, ordered32-record chunks with stable identity
mapping, and a raw small-tree representation on identical operation traces.
Use the existing exact12-word block codec and independent full-tree/full-render
oracles. The candidate's authoritative record store must be compressed pages,
not an expanded per-node mirror. Decode scratch is bounded per touched page.
Local insert/split/merge updates only affected directories/links; parents are
stable identities so moving a parent does not rewrite all descendants' addresses.
No uncharged global rank repair. Repeated, unique and high-entropy exact words;
1/9/32/256/1024 nodes; insertion/removal/relocation, page-boundary subtrees, dense
layout/clip closure, thousands of changing small properties. Seed20261029.

Locality ledger: count identity/index accesses, decoded rows/words, page touches,
metadata maintenance, source/description/dependency closure, old/new damage
work, CPU scratch and rewritten/moved/uploaded bytes. Charge subtree-start
lookup separately from extent enumeration. Oracle/diagnostic extraction work
must be separated and labeled, never excluded from a purported production path.
A restricted public Source paint fixture will register identity/geometry once,
then update through existing APIs and a direct binding plan without per-update
snapshot extraction. Expose any fixture-specific callback or missing generic
runtime integration; it is not proof that all GPUI updates use this store.

Storage ledger: live encoded/raw payload, page headers/links, identity directory,
COW address directories, unused slots/allocator fragmentation, scratch, every
prepared/submitted/visible root and all leased resource bytes. Tiny raw fallback
must include its metadata and allocation rounding. No total-memory claim from
GPU payload compression alone. Measure retained high-water after churn.

Publication: retain immutable page/root versions until both semantic ownership
and all submitted GPU fences release them. Latest eligible authority differs
from latest requested/failed source epoch. Exercise overlapping submissions,
stale-before-submit, stale-after-submit, failed-newer request, out-of-order CPU
completion notifications, generation reuse, backpressure and safe reuse. Keep
serialized staging baseline. Resource tests must include actual text-mask and
image bytes consumed by GPU, not merely integer token liveness. Resource-byte
lifetime tests alone do not prove general text/image rendering integration.
Do not describe queue writes as coherent shared host memory. Charge stale upload
waste independently of visible-state correctness.

Stages: (A) deterministic incremental-storage/lifetime models with bounded
mutants; (B) actual Vulkan overlap/reuse and resource-byte consumption; (C)
ordinary public Source binding trace/full render oracle. Freeze before each
execution gate, preserve every failure, unique target, pinned locked/checksum
Cargo builds, before/after inputs, actual ELF/embedded shader/readback evidence.
No adoption or performance gate is relaxed. No timing until all three stages
qualify; any later timing needs its own frozen protocol and complete controls.
