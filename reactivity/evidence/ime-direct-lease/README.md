Source and original replacement stay fixed for an active composition. Equality compares the previous raw marked middle, or the original Source replacement for initial/cleared marks. Clear clones Source only when necessary. A branch-derived changed flag removes the old temporary display clone/drop. Other publication and C/P reference counting remains.

One ICU iterator now resolves both nearest cursor endpoints and decoration floor/ceil, stopping at the first boundary at or after marked finish. Both raw endpoints are admitted inside that interval; adjacent boundaries suffice, with downstream ties. Segmentation still sees the joined string from byte zero, so combining, ZWJ and RI context across either seam is retained. No cached boundaries or ASCII restart were added.
