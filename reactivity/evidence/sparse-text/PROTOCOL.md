# Sparse text publication: preregistration

Base `75a9e2b06b`, excluding the rejected text-witness replay candidate.
Use the state campaign's fixed five-size, five-pair complete-operation matrix,
200 warmups and 2000 measured writes per process. Advance only with >=20% lower
median process CPU at 1000 static labels, <=5% regression in every other size,
exact public behavior and a falsified negative control. Preserve all raw batches,
hashes, cold/peak/storage costs and failures. No threshold tuning after results.
This admits further native trials, not a competitor win; the latter still needs
equivalent rendered workloads and two hardware classes.

Hypothesis: after an ordinary direct text binding and the ordinary layout compute,
the actual changed-layout-write counter can certify unchanged placement. A
bounded transactional text-run replacement and sparse candidate sheet can then
avoid rebuilding unaffected paint and semantic rows. Fixed size alone is not a
certificate. Keep full preparation for topology, layout movement, fanout, pending
candidate, selection/IME, clip/viewport and unsupported resource changes.

Initial scope: one changed ordinary text sink, no outstanding candidate, no
logical metadata/viewport/image state, and no changed computed layout. Replace
only equal-length admitted glyph runs whose resource keys already exist in the
canonical scene, with exact common-state equality. Resource/key/length mismatch
falls back without mutation. Do not grow a historical resource bank or keep an
unbounded journal. Preserve old acknowledged text/geometry until actual ACK,
and retain an older complete candidate when newer work fails.

Application View/Signal/Source APIs remain unchanged. Canvas may gain an additive
positional text-run operation with the same caller-token discipline as paint
slots. No new production unsafe, dependency or vendor patch is planned.

Oracles: unchanged full preparation and fresh ordinary windows; text, geometry,
damage and pixels at each admitted/fallback transition; pending ACK, failed newer
preparation and recovery; source identity/fanout/remount, width/length/Unicode,
font/DPI/transform/clipping/alpha, selection/IME and accessibility fallback.
The bounded mutant must violate the new admission certificate and fail an exact
semantic/pixel assertion. Report cold header/per-text storage, warm requested
allocations and RSS separately. Do not claim native/GPU savings from CPU recording.
