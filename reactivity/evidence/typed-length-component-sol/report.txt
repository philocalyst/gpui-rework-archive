Public API and ownership

Length::{Auto, Points(f32), Percent(f32)} replaces Option<f32> only for the
width/height domain. Percent(100.0) means100% of the parent's content dimension;
values above100 are valid. Points and percentages must be finite/nonnegative.
The existing declaration validators reject invalid authoring before Cephal;
Cephal receives admitted percentages divided by100. Auto is an explicit value,
separate from Contribution::Inherit, with unchanged typed contribution presence.

Examples:
  div().w(320).h(Length::Percent(100.0))
  div().size(Length::Percent(100.0))
  div().w(&registered_length_signal)
  div().w(flag.map(|value| if *value { Length::Percent(50.0) } else { Length::Auto }))
  win.set_property(target, WIDTH, Contribution::Set(Length::Auto))?

WIDTH/HEIGHT are now Property<Length>; the catalog still has14 entries.
The deliberate cold boundary is PropertyValue::Dimension(Length). Points/percent
units cannot enter gap/font-size through IntoProp. Ordinary numeric width/height
builders preserve the prior IntoLength -> f64 -> f32 conversion, including wide
integer midpoints, overflow and negative-subnormal rejection. An internal explicit
numeric operand retains f64 until admission; there is no NaN/signed-zero sentinel
encoding. Direct Length signals and typed maps reuse the same source codecs and
owner-relative fanouts, without per-control tables or an arbitrary schema registry.

Exact author equality keeps the variant tag and original f32 bits, including
signed zero. Ordinary PartialEq remains numerical. Layout style interning and its
retained color/layout projections use the same exact unit/bit comparison. The
shared lowerer handles roots, ordinary containers and Scroll. Uniform-list row
materialization still precedes containing-block layout and requires an explicit
point height: Auto gives MissingViewport, Percent gives UnsupportedStyle. Relative
list heights remain an explicit follow-up, not a fabricated containing size.

Inspector and migration

Typed setters now take Length::Points(x) in place of Some(x), and Length::Auto
in place of None. The cold Dimension boundary changes identically. The inspector
increments percentages in percentage points, preserves their unit, and retains
Set(Auto) separately from Inherit. The contained value editor uses one shared
Length Display/FromStr pair for bare point numbers, percentages with %, and auto.
Invalid parsed values still reach the canonical property validator, which rejects
without mutating a contribution. Semantic JSON continues to serialize the same
acknowledged geometry; it does not invent authored style/unit fields or replay
capabilities. Historical evidence fixtures remain historical snapshots, not a
source-compatibility claim for this authorized public API change.
