# Combined property selection, count and presentation qualification

Main shipping source `c717df64a9b492b445fa97647deb880fb21b9ef6` integrates
cached-edge caret lowering, compact 64-byte presentation rows, contained property
actions, exact property/description identity accounting and public mounted-target
selection with canonical state replies. Producer results retain their original
pins in [the API archive](../property-selection/final/README.md),
[the union archive](../property-change-union/README.md) and
[the presentation archive](../presented-basis/ADOPTION.md).

The combined campaign passes 651 GPUI/GPU cases and doctests in 58 harnesses,
29 ignored, including 46 actual Vulkan readback cases. Strict all-target Clippy
and formatting pass. Apple AArch64 and Windows MSVC desktop+parallel+optional
shader all-target compilation pass with build-std; these are compilation checks,
not foreign-OS execution. The nine Hummingbird tests, five external catalog tests
and real shared executable headless transcript pass.

Actual private X11/Registry execution passes Hummingbird's explicit GPU transcript
(eight acknowledged frames), Unicode text geometry/edit/reactivation, the
contained property editor pointer/server-pixel test, checkbox state/actions/events,
late accessibility service/owner replacement, exact Future cancellation/wake,
and cold blank→software→GPU handoff. Vulkan uses Mesa llvmpipe. This establishes
behavior, not hardware timing, RSS, native HDR, foreign backend conformance or
complete application/framework parity.

The independent public replay uses the copied, unchanged property_editor example,
Window::document and a real private AT-SPI Registry. Checkbox Action enables
inspection, library Action selects its root, EditableText enters 193.25, Apply
changes its acknowledged width, Inherit restores 120 and the original width, and
Refresh returns 120. Acknowledged text and character extents are checked after
each operation. No private host/model seeding, synthetic ACK or application hook
is used. The frozen client is identical to the producer's passing client; its
source and checksum remain recorded separately from the application binary.

All 2,029 guarded library/vendor/manifest/application inputs, root Cargo compiler
configuration and copied executable hashes remain unchanged across their gates.
Owned displays/processes are retired. Raw commands, Cargo units, compiler version,
source guards, executable digests, native transcripts and cleanup results are
preserved here. Large raw logs are gzip-compressed without changing their bytes;
raw-files.json records original hashes and sizes. Frozen executables remain
outside Git at their recorded paths, sizes and SHA-256 values. Debug artifact
sizes identify controls, not shipping binary sizes.

The Canvas source and its dependency/compiler inputs remain equal to the separately
qualified 193-case source [538191fa01](../caret-main/README.md); this campaign does
not rerun or retag that suite. The current [source bill](../core-lines/README.md)
is 30,467 non-test code lines including 18 build-script lines. All test, application,
vendor, generator and evidence costs follow their separate ledgers.
