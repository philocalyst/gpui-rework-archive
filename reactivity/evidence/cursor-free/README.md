# Cursor-free raster source gates

These source-local logs came from the isolated cursor-free and scheduling
follow-up worktree. Raw logs/assembly are losslessly gzip-compressed and checked
by `raw-sha256.json`. The original `binary.sha256` belongs to the initial7006
artifact; later builds replaced that target file. Root does not claim an
independent recheck of that overwritten binary. The later frozen96f4 consumer,
fresh actual library/binary identities, paired controls and rejected follow-ups
are preserved in [the full representation controls](../core-representation-controls/README.md).
