## Hypothesis and implementation boundary

An exact one-text edit with unchanged layout/topology can reuse complete P
geometry and replace one canonical Canvas run despite unrelated list/metadata
state. Existing blanket feature guards discard that locality. Resolve exact
acknowledged identity (logical and P indexes differ under virtualization), use
that sheet's transform and clip, retain the ordinary Canvas run/resource proof,
and patch P text and interaction geometry only on ACK. Keep ordinary no-feature
path direct. Active editing/inspector state may fall back conservatively.

No application API, dependency, shader, color-quality, ownership or task behavior
changes. No new unsafe. No replacing the whole display tree before measuring
this prerequisite. New masks, changed grouped lengths, clip chains and changed
layout continue to fall back if the existing certificate cannot admit them.

## Stages, fixed before results

1. Semantic qualification and instrumentation: exact full-render differential,
   acknowledged text/geometry/identity, real Workload admission/fallback counts.
   If the actual stream never admits, report that failure and do not claim an
   end-to-end performance win from a hand-picked string fixture. A subsequent
   representation change needs its own preregistration.
2. Candidate/default and X11 GPUI+Canvas tests and strict all-target Clippy;
   native port tests and actual native Todo/Library/IME scripts. Freeze source,
   checksum all inputs and preserve binaries before rebuilding profiles.
3. Falsification: mutate exact P-row identity resolution so omitted overscan rows
   select the wrong P row. The public semantic/pixel oracle must fail. Preserve
   the mutant and failure; do not count an admission-only assertion as proof.
4. Cost trial only if semantic gates pass and representative admission exists.
   Reuse the existing complete `native::scroll_bench::complete_workload_cost`
   workload byte-for-byte and its ten cases. Fifteen fresh paired process groups
   per case, alternate control/candidate order by pair, shuffled group seed
   20261029, 16 warmups and 64 measured updates. Preregister the exact process
   manifest before running. Primary `stream` median paired process-median ratio
   <=0.8, all other cases <=1.05. Report p50/p95/p99, cold construction, first
   frame and first update, separate invoking-thread allocations and retained
   image/metadata bytes. Keep all failures and uncertainty; no cutoff retuning.

Full original control pixels, final source epochs and admitted work counts must
match per process. Timings never overlap compilers, tests, allocation probes or
cleanup. Keep >=8 GiB free. Inventory shipping source, retained headers, whole
example ELF, changed linked routines and stack separately. Software Vulkan and
private X11 do not meet the physical hardware or WSI/scanout comparison gate.

## Required adversaries

- Text before and after a virtualized list; omitted overscan rows shift P rank.
- Unchanged ordinary scroller, transformed ancestor and clip; unsupported chains
  fall back with exact pixels. Unrelated image/semantic metadata cannot grant
  authority or lose resources.
- Old P text, target, geometry and list membership remain before ACK; fresh
  text and exact pixels appear together after ACK.
- Repeated edits, coalesced unacknowledged candidates, resize and presentation
  loss; a failed newer edit cannot revoke an older eligible complete token.
- Changed text length/new glyph lease and geometry change take complete fallback.
- Owner updates, task-dependent updates, topology and row retirement retain
  conservative existing behavior. No task replay or hidden batching semantics.
