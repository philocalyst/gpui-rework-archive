# Text stream experiment: unadopted, timing unresolved

The frozen [functional/codegen checkpoint](final-public-controls/README.md)
preceded the performance campaign. Its statements that timing had not run
describe that historical checkpoint. The [actual campaign](failed-capture-62be/README.md)
then stopped on a native-client watchdog after 122 complete observations and
one failed observation. **All 70 cell gates and 160 metric gates are unproven.**
No performance retry, resampling, threshold change or source tuning followed.

Two separately authorized [functional diagnostics](native-diagnostic-62be/README.md)
ran the exact frozen binaries with clocks disabled and DBus/strace monitoring.
Both completed, including 128 selections, failed presentation retaining old P,
repair and normal close. Those changed observation conditions do not explain
or clear the original timeout. No speed, equivalence or adoption is established.

This directory preserves the complete experiment's evidence from
`6b51f885fffe4d5a18b3357639f6360da07a8b70`; its original source pins and failed
attempts remain distinct. Shipping text code is unchanged. The proposed source
is `9f934e85b5b6211a3985b830ce4dcc672a1ffe16`; it removes repeated boundary
regrouping but has no measured retained-heap improvement. Several constructors
grow despite smaller complete linked callers. Missing IME, masking, preferred
column navigation and autoscroll are not covered by these controls.
