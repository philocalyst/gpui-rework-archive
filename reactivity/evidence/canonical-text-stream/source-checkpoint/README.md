## Completed ownership and source authority

Its initially empty stop Vec cannot escape: Canvas appends existing producer stops before the sole successful `Ok(TextLayout)` tail wraps Details in Arc. `TextSite::shape_for` assigns its new cached layout only after that call returns Ok. A failure drops speculative Details or preserves the earlier cached layout. The runtime's complete local C geometry column and exact ACK publication are unchanged. Every successfully completed interactive map contains an existing byte-zero caret, including the empty document's single terminal stop. `Option<Vec<Stop>>` therefore encoded a redundant published `Some(empty)` state. An empty Vec now means passive/discarded interaction; an active empty source still has its real byte-zero stop. No terminal point is synthesized. `has_interaction` tests this completed authority and replaces two caret-at-zero cache probes. Existing explicit `discard_interaction` still detaches shared Arc geometry, drops interaction storage and preserves glyphs/font/source placement. `Some(empty)` existed only inside unpublished construction; no a11y/editing consumer could observe it.

This spike does not conflate display glyph clusters with source bytes: canonical offsets remain ICU grapheme boundaries in admitted source text, and the glyph/source-domain separation is unchanged. ## Traversal and fallback costs

Producer boundary groups contain either one coalesced mask-3 stop or upstream then downstream stops. Consecutive downstream/upstream stops with distinct source bytes form the selectable interval. The new adjacent-stop traversal preserves both distinct affinity positions and skips only the within-byte alias pair. It does not merge distinct caret geometry or infer lines from y. It uses two monotone line indices, initialized by two source-table partitions, to recover downstream source ownership and retained upstream geometry. The indices add stack state and comparisons; short labels must pay their real cost. Zero-width/hard-break direction still uses the existing run-table fallback.

`boundaries_in` admits both inclusive source endpoints in the same stop stream, returning byte boundaries without geometry reconstruction. It intentionally collapses byte aliases only for native character indices; the caret map keeps both affinities/positions. Native position conversion keeps the existing source/field/ID checks and affinity fallback. Native publication consumes one grapheme walk to emit character lengths and geometry together. A separate cheap canonical boundary-count pass preserves exact capacities for positions/widths. No geometry arrays allocate for unplaced text. This count pass, its partitions, AccessKit's own length validation, both geometry buffers and their construction peak remain charged. No allocation or retained-byte reduction is claimed before matched owner ledgers.

No explicit SIMD implementation is justified in this slice: affinity/line ownership and per-interval source recurrence are ordered, while twelve-byte interleaved stops are a poor independent-lane input. The adjacent integer boundary checks expose a simpler linear stream to the optimizer. Optimized assembly must establish what actually lowers; source appearance is not a vectorization or speed claim. The original exact f32 operations and order remain unchanged.
