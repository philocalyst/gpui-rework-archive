New public methods, branches and iterator state are charged. Tests, comments, evidence and the public editor example are outside the core bill. `core-delta.json` gives per-file changes. There are no new owner fields, retained indexes, Cell/RefCell/Rc, unsafe blocks, dependencies or epoch frameworks.

Performance and code/frame qualification remain open. Before any timed run, frozen matched ordinary binaries must exercise actual public interaction latency/work counts and native idle/busy/frame/late-close behavior, plus isolated canonical queries and native character-index transport. A preregistered per-cohort equivalence/noise policy must reject reproducible losses; aggregate wins cannot hide a losing cohort. Normal binaries must have no counting allocator. Codegen uses the tracked root flags with explicitly appended stack metadata and ordinary public callers, without caller-specific inlining changes. Source count and nominal iterator size alone do not justify adoption, speed or stack claims.
