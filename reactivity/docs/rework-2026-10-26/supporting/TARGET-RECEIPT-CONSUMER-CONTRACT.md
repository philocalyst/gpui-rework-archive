# Target-relative receipt consumer: minimal host integration contract

## Exact handoff boundary

The cloud can read the concrete Canvas binding and the authorized attached R1 executor. The host owns the newer compact catalog, neutral plan, and actual target wrapper; their current implementation is not present here. This is a consumer contract and test delta, not a second executor/catalog or a claim that a production consumer is already implemented.

Canvas publication proves accepted canonical C and owns its exact batch, semantic partition and optional closed logical receipt. It does not prove target pixels. R1 CompletedWrites proves a joined leaf execution, not image publication, destination copy, native presentation or GPU fence retirement.

## Structural removal

Use `frame.closed_dependencies()` as the already-computed logical closure. Feed its immutable closed logical nodes into the shared physical group/resource/tile expansion. Do not clone a private logical graph or recompute closure against a newer graph. Missing receipt, hard Full, incomplete physical dependencies or a receipt-chain gap take the ordinary full path.

Canvas stores only the latest bound edge, not an implicit receipt history. Therefore the consumer must observe each successful canonical admission even when it skips output, or detect a predecessor gap and render fully. Do not retain borrowed Canvas views across later mutation; retain the admitted immutable backend snapshot/leases and bounded physical union instead.

Each target retains only its domain, actual completed output revision, admitted latest revision, and the pending physical tile union. The domain includes actual storage identity, surface generation, extent and format/configuration. This is necessary target damage state, not another semantic owner/SceneGroups catalog. Consume each accepted edge once: union BOTH old and new admitted supports, including removal and exposure. Complete that physical expansion while BOTH exact old and new admitted backend snapshots and resource leases are available. Only after expansion may the edge views be released and just the tile union retained. Missing old physical metadata/lease requires Full; latest C cannot reconstruct a skipped removal. An accepted but unrendered C advances pending-to, never completed-image authority. Failed canonical preparation produces no new accepted edge.

Do not call this a global scan, bin, upload or ordinal-remap elimination: stock packed CSR words still refer to current dense painter ordinals. A general insertion requires checked projection against the bound current scene or a host-owned stable physical-address leaf. Price any global projection explicitly. Material opacity/image changes revoke coverage/cut proofs; same-alpha RGB-only reuse needs the actual checked transaction invariant.

## Transaction boundaries

1. Capture immutable accepted frame, target domain, pending-from/to and all selected jobs. Synchronous exclusive borrowing can forbid appending later receipts during execution; encode that exclusion rather than inventing an unnecessary queue.
2. Complete every fallible admission/allocation and resolve every current contributor before writing. A failure here preserves old complete pixels and the pending union.
3. Revoke image authority before the first possible physical write. Partial execution failure never restores the old lease. Preserve pending damage; if it does not cover every possibly touched write, require full recovery.
4. Only successful joined jobs AND any required copy/upload/fence complete the exact captured target revision. Clear only the captured prefix. If concurrent receipts are supported instead of excluded, retain the newer suffix union explicitly.
5. Packed/cache-image completion and external destination-copy completion are distinct physical authorities. A successful cache repair plus failed destination copy cannot mark that destination complete.

## O(1) non-graphical index rebase

Under the new strict Canvas guard, ALL zero-actual-mutation publications require the mandatory non-graphical closed proof. A bound empty checked-slot witness is thus an edge-local library-issued fact, not caller edits. After exact predecessor/domain validation, the consumer may rebase the admitted index revision without scanning/replacing group payloads. Mint snapshot-local GroupId lazily from CURRENT admitted revision plus local group cursor; never retain stale C1 GroupIds under C2. Physical owner/bank birth identity stays distinct from current accepted epoch. Missing an intermediate metadata receipt is still a real chain gap. Canvas publication alone neither updates target-complete authority nor ACKs pixels.

## Required host tests (actual consumer, not metadata simulation)

- Seed target C1. Accept C2 left paint, C3 right paint, C4 revert-left without rendering intermediates. Latest receipt describes only left; final target must still repair right. Compare ALL active pixels to fresh C4, including untouched sentinel/padding policy. The separate Canvas fixture supplies this exact receipt history but does not qualify target repair.
- C1 complete; C2 removes an overlapping translucent group; C3 moves another group. Union old/new support and replay all current ordered contributors. Include ordinary popover insertion/removal; no case-name fallback.
- Fail a newer staged canonical publication and a checked-slot coverage attempt between accepted edges. Old binding, pending journal, target completion and pending tile union must be unchanged.
- Reject selected-output length or membership before any write. Old completion remains eligible and pending union survives; retry succeeds exactly.
- Inject failure after a physical row write. Old completion becomes ineligible; retry latest C repairs the whole pending union or takes full recovery. Complete pixels must match cold output.
- Drop one edge, change surface generation, extent, format or storage identity. Require explicit full recovery, never reuse a matching scene sequence as target identity.
- If synchronous borrowing excludes new C during jobs, require a compile-fail ownership test. Otherwise append C5 while C4 jobs are captured; C4 completion must not erase C5 damage.
- Change alpha and immutable image material while geometry/order are equal. Old cut certificates must not remain eligible.

Record visits, projection/bin work, allocations and retained/staged/retired capacity separately. Pending bitset/row descriptor memory, old/new catalog leases, output owners and failed-attempt capacity growth remain real costs. No timing, Rust compilation or host target qualification was performed here.
