This separately registered, frozen experiment compares original, certified-solid
and four-row shaders over the same historical core and mapped Todo fixture.
The [report](capture-2026-10-24/report.md) retains all qualified and rejected rows.
It does not replace either earlier Todo campaign.

Main adopts only the certified-solid formulation. The four-row version remains
unadopted because its measured overloaded receipt throughput is worse. Every
animation profile still fails its required work gates. Qualified two-second Busy
samples are too variable to establish a broad CPU saving.

Root independently verified the exact sets, hashes, types and modes of both
archives and reproduced `summary.json` byte for byte. The source capsule's three
measured target ELFs and four quarantined predecessor ELFs are distinguished in
[integration-review/independent-capsule-audit.json](integration-review/independent-capsule-audit.json).
Captured source/ELFs remain immutable; Main's formatted helper scripts are
separately versioned postcapture code.
