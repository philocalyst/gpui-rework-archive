# Examples

Complete programs, each showing one area of GPUI. Every page holds the whole
source. On the [GPUI site](https://gpui-ce.github.io), the examples run live in
the page, in your browser.

To run one yourself, clone the repository and run it by name:

```sh
git clone https://github.com/gpui-ce/gpui-ce
cd gpui-ce
cargo run --example counter
```

New to GPUI? Start with [`hello_world`](examples::hello_world) and [`counter`](examples::counter), then follow the
[tutorial](crate::_documentation::tutorial), which builds [`todos`](examples::todos) step by step.
