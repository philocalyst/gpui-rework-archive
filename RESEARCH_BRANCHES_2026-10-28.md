**Preservation is not adoption.** This snapshot includes candidates, baselines, deliberate negative controls, qualification checkpoints, and rejected experiments. Read each dossier’s disposition and exact protocol before interpreting a result. No overall win over ZGX is asserted by this index. Software-Vulkan results do not establish hardware GPU or display latency superiority.

## What is preserved

- The commits and history reachable from the listed branch tips, including source, protocols, committed raw evidence, failures, and review records.
- [RESEARCH_MANIFEST.tsv](RESEARCH_MANIFEST.tsv) records full commit SHAs, commit timestamps, worktree paths at capture, and latest commit subjects. Links below use immutable SHAs; branch tips may advance later.
- Ignored build outputs, executable archives, reference checkouts, and evidence directories outside Git are not included. Dossiers may reference absolute paths on the research machine; those paths are provenance, not downloadable artifacts.
- Historical statements such as “local only” or “not pushed” inside sealed dossiers describe their original recording time. This index records the later publication without rewriting those dossiers.
- The original `wt/*`, `stash/*`, `ns/*`, production branches, tags, manifests, and release-asset checksums are preserved. Only the default `archive-index` documentation is extended.

## Restore a branch

```sh
git clone https://github.com/philocalyst/gpui-rework-archive.git
cd gpui-rework-archive
git fetch origin '+refs/heads/local/*:refs/remotes/origin/local/*'
git worktree add -b review/tree-parent-columns ../gpui-tree-parent-columns origin/local/tree-parent-columns
# For the exact captured tree instead of a moving branch, use the manifest SHA:
git worktree add --detach ../gpui-tree-parent-columns-snapshot 97731fc49c65d51e8253ea3bc572cdd9150334be
```

Use each experiment’s pinned toolchain, build profile, and evidence instructions. Baseline and deliberately broken branches are part of the experiment, not interchangeable implementations.
