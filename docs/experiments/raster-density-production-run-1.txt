The benchmark validates CoordinateSpace::new(camera).raster_scale() against the
same max_scale/eighth-step formula, then alternates paired variants. A recomputes
the formula per operation; B reads the real cached public getter per operation.

This run is not a valid getter comparison: the cached side black-boxed the
result rather than the CoordinateSpace reference, allowing its load to be
hoisted. Corrected run 2 makes both inputs opaque before each operation.
The high host load also widened timing tails. This output is retained as
experiment history, not performance evidence for the final implementation.
