The benchmark constructs a real CoordinateSpace from one shared camera matrix.
Before timing, it validates CoordinateSpace::raster_scale() against the same
max_scale and eighth-step bucket formula. A recomputes per operation from an
opaque matrix. B performs the actual public getter through an opaque
CoordinateSpace reference on every operation, preventing the reference/load
from being hoisted out of the loop. The paired timer alternates A/B order.

This is arithmetic versus a getter load, not a shaping, rasterization, or
whole-frame benchmark. The earlier full-suite density sample is retained in
raster-density-production-run-1.txt; its cached value was not read through an
opaque CoordinateSpace reference and should not be used for this comparison.
